# Fixtures for the Phase 7 demo

`ear-reddening-1846.sgf`: Honinbo Shusaku (Black) against Inoue Gennan Inseki (White), played on
1846-09-11, 14 and 15, Black won by 2 points (the "ear-reddening game"). It is a game
record of 325 moves from 1846: a bare list of moves, with no creative content, so it is in the
public domain whatever the licence of the copy it came from; the file carries no commentary. The move list was taken from the copy at
`akitaonrails/frank_go` (`data/games/famous/1846-ear-reddening-game.sgf`); LiGo added only the
root properties `GM`, `FF`, `CA`, `SZ[19]`, `KM[0]`, `RU[Japanese]`, `GN` and `GC` (the original
had no board size or rules).
