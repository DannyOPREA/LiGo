# Where LiGo's puzzles come from

The sources list for the credits page (Phase 9, unit 9.8) and anyone reusing the set. Each
puzzle's own `provenance` field says the same for that puzzle.

| File | Puzzles | Source | Licence | Checked with |
|---|---|---|---|---|
| `generated-001.json` | 240 | Generated by LiGo's own generator (`tools/puzzles`, version 1, seed 1, unit 8.4): catalogue eye spaces, each answer proved by an exact search over goban-engine (ADR 0024, ADR 0025) | MIT (LiGo's own content, COPYING.md §2) | KataGo v1.18.1 (MIT) with the g170 test network `g170-b6c96-s175395328-d26788732.bin.gz` (sha256 `f5d32604e3675c480c7c8f6aa579a1ea857135628a0afccc8fa56330fbacd38d`), shipped in KataGo's own MIT repository (ADR 0025 §2), 400 visits |

Rebuilding with the same seed gives nearly the same set, not always the identical one: KataGo's
verdict and the solver's time limit vary a little from run to run (a rerun of seed 1 changed 4
of the 240). The committed file is the set; it is never regenerated in place.

Tools the set was made with, not copied into it: goban-engine (Apache-2.0, the rules), KataGo
(MIT, the second opinion), KaTrain's tsumego frame (MIT, ported in `src/frame.ts`).

Not yet here: the *Gokyō Shumyō* (1812) tail (ADR 0024 §2), waiting for a reachable scan and its
rights line. gogameguru's collection is not used (non-commercial only, ADR 0024).
