# i18n rules
- Every user-facing string goes through an i18n key, with the English source text in
  `lila/translation/source/*.xml`. No hard-coded English in views or TypeScript.
- `modules/coreI18n/src/main/key.scala` is generated (`lila/bin/i18n-file-gen.ts`) and
  `translation/dest/` is crowdin output: never hand-edit them.
- Reuse existing chess-neutral keys ("Resign", "Draw offer" etc.) where the meaning is the same.
